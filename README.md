# Electric Vehicle Sales Analysis Dashboard

## Project Overview

An interactive Power BI dashboard created to analyze electric vehicle sales, pricing, performance, and customer-related data.

## Tools Used

* Power BI
* Power Query
* Data Cleaning
* Data Visualization

## Key KPIs

* Average Battery Capacity
* Average Range
* Average Price
* Annual Sales Units
* Customer Rating

## Dashboard Analysis

* EV Sales by Brand
* EV Sales by Year
* EV Models by Body Type
* Average Price by Brand
* Top 5 EV Models
* Price vs Range Analysis
* Battery Capacity and Vehicle Range

## Dataset Fields

The dataset includes information such as:

* Brand
* Model
* Year
* Variant
* Price
* Battery Capacity
* Range
* Charging Speed
* Acceleration
* Top Speed
* Horsepower
* Torque
* Drive Type
* Seating Capacity
* Body Type
* Safety Rating
* Country of Origin
* Market Segment
* Annual Sales Units
* Customer Rating
* Warranty Years

## Dashboard Preview

The Power BI dashboard provides an interactive view of electric vehicle sales and performance using charts, KPI cards, filters, and tables.
